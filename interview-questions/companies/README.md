## JSON结构

- `index.json`：各公司文件、数量和统一计数口径。
- `sources`：来源网址、标题、原采集时间、类型与正文hash。正文日期和收录时间不冒充发布时间；未知时间保留null。
- `sessions`：原文面经段落/轮次及日期依据。字节日期是作者自述；腾讯只给月日，年份未知；理想和富途发布较早，实际面试日期未知。
- `questions`：稳定ID、公司内顺序、练习提问、来源、段落及原题位置。`question_kind`区分主问/追问/表达要求，`follow_up_of`保留追问关系。
- `needs_current_fact_check`：涉及指定模型机制的题应先查当期官方资料，不把面经作者说法当作技术事实。

没有参考答案或模拟面试官意图，避免把整理者推断当原文事实。完整采集档案保存在采集工作目录；此处保留来源网址和hash以便追溯。

这些JSON已接入首页「大厂面经」：按公司和面经段落筛选，支持答题、切题、提交已答题查看规则练习反馈。草稿、选定公司和题目保存在本机独立存储项，刷新或切换后可恢复。

服务器使用公司Slug和稳定题号读取权威题库，不采用客户端传入的题面。语义模块是整理者为复用练习评分规则添加的分类，不代表原面试官评分标准。

原150题全刷题库和141题更新候选保持独立；公司面经入口无需先完成全刷。
